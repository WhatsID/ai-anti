# Codex 用户级工作流入口

显式读取本文件所在源码仓库的 `../../core/WORKFLOW_ENTRY.md`，不要从业务 cwd 猜路径。
共享入口定义模式优先级、任务规模与常驻边界；用户和项目规则按工具原生优先级执行。
项目业务参数本地优先；已有项目明确调用规则须遵守，冲突须报告，不能悄悄覆盖。

简单答疑直接回答，小任务直接做。solo 不评审、不委派；rules 按共享默认阈值加项目风险
分流；auto 自行判断但保留高风险评审；force 对实质工作走接力。
命中完整接力时读取安装的 `codex-relay/SKILL.md`；仅需独立评审时读取
`claude-review/SKILL.md`。技能路径由安装的 skill 解析，不假设业务仓库内有副本。
缺少所需技能时报实际缺口，不能声称完成。

读到入口或匹配技能不是实施授权。仅调查/计划时保持边界；被委派实施者或评审者
不递归自动启动接力。评审细节按需读取共享 `REVIEW_PRINCIPLES.md`，外部 CLI
调用前读取 `CLI_DISCIPLINE.md`。不把本文加载等同于完整接力已执行。

已激活的同任务阶段衔接，按同源 `core/WORKFLOW_CONTINUITY.md` 实际读取与执行；
rules/auto 不按单阶段大小省略门禁。任务记录不是授权，plan-only 不自动实施。
